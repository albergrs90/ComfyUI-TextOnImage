# ComfyUI-TextOnImage

A simple and efficient custom node for [ComfyUI](https://github.com/comfyanonymous/ComfyUI) that allows you to overlay customizable text onto your generated images.

## ✨ Features
- 🔤 **Custom Text Overlay**: Add text directly to your images with precision
- 🎨 **Full Customization**: Control font size, color, position (X/Y), and alignment
- 📦 **Font Support**: Works with `.ttf` and `.otf` files
- 🌍 **Multi-language Ready**: Includes English & Chinese font support out of the box
- ⚡ **Lightweight**: Optimized for fast processing in any workflow

##  Installation

### Option 1: Using ComfyUI Manager (Recommended)
1. Open **ComfyUI Manager**
2. Click **Install Custom Nodes**
3. Search for `ComfyUI-TextOnImage`
4. Click **Install** and restart ComfyUI
